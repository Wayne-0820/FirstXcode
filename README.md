# 問道

一款修真放置遊戲，可以直接裝到 iPhone 主畫面上玩。

不需要 Xcode，不需要 Node，不需要安裝任何東西。你的 Mac 上已經有的 Python 就夠了。

---

## 玩法：互相咬合的系統

**修煉** — 打坐賺靈氣 → 蓋修煉設施自動產靈氣。

**機緣** — 每隔 100~260 秒，畫面上會飄出一個 🌀，12 秒內點到才算。點下去才揭曉是什麼：靈氣爆發（十分鐘的產量）、頓悟（打坐 ×7）、靈感（修煉 ×7）、天降橫財（天才地寶），或者運氣不好抽到心魔（修煉減半）。**看不到結果才點下去**是刻意的——直接顯示的話沒人會去點心魔，那個壞結果就形同虛設。

**武學（抽卡）** — 在「問道石碑」用靈氣叩問，抽到武學卡。三大類：招式（戰力）、輕功（天才地寶）、內功（靈氣／打坐／悟性）。
- **勾玉升級**：抽到重複的不會白抽，鑲一顆勾玉升級。藍勾玉 5 顆 → 黃勾玉 5 顆 → 紅勾玉 5 顆，共 15 級，每顆 +20% 基礎加成。
- **20 抽保底**：連續 20 抽沒抽到還沒學過的，下一抽必得新武學。
- **兌換碼**：私人用。碼不是明碼（原始碼裡只放雜湊值 `2088437879`，是 `state.js` 裡 djb2 算的）。`5580` → 免費叩問 1000 次（等於一次養滿）。要改碼：算出新碼的雜湊填進 `REDEEM_CODES`。**注意這是單機網頁，決心破解的人仍能反推——只是不讓它明晃晃地躺在原始碼裡。**

**宗門（弟子）** — 開宗立派，用悟性招募弟子。弟子跟其他東西都不一樣：**招進來之後會自己隨時間變強**。每個弟子有「道行」，掛著就往上爬（每 2 小時一級，最高 10 級），加成跟著長。而且**道行不吃離線上限**——靈氣離線最多算 8 小時，弟子卻是放多久長多久，放一週回來是真的長大了。宗門等級（已收弟子數）越高，越後面的弟子才解鎖。這是唯一「什麼都不做也在進步」的系統，正是放置遊戲的味道，也是「飛昇之後沒事做」的解答之一。

**境界突破** — 攢夠靈氣就能衝關（凡人 → 煉氣 → 築基 → 金丹 → 元嬰 → 化神 → 煉虛 → 合體 → 大乘 → 渡劫 → 飛昇）。
突破**成功**：靈氣歸零、設施與功法全部散去，換來永久的修煉倍率和**悟性**。
突破**失敗**：只有靈氣歸零，境界、設施、功法全都留著——白跑一輪，但不掉進度。

**商店** — 三個分頁：

| 分頁 | 用什麼買 | 突破後 |
|---|---|---|
| 修煉 | 靈氣 | 散去 |
| 功法 | 靈氣 | **散去** |
| 法寶 | **悟性** | **永久保留** |

**音效** — 全部用 Web Audio **當場合成**，一個音檔都沒有（跟太極圖示一樣，都是程式算出來的）。打坐是木魚，連點時會沿著五聲音階往上跑成一段旋律；突破、抽卡、機緣、打怪各有各的聲。右上角 🔊 可以靜音，這個偏好記在**裝置**上（重置存檔、搬存檔都不影響）。iOS 規定要先點一下畫面音訊才會啟動，所以第一次進來是靜的，很正常。

### 打坐為什麼是「產量的百分比」

`content.js` 裡的 **`clickShare`** 是這個遊戲最重要的一個數字。

原本打坐給的是一個**固定數字**，但產量是指數成長的（境界倍率一路從 ×1 到 ×6,000,000）。結果是：把打坐加成全部買滿（×90），到金丹時一次打坐也只值 **0.006 秒**的產量，到化神更是直接歸零——狂點一百下不如放著不動半秒。**打坐在數學上死了，加動畫加暴擊都救不回來。**

改成「底線 + 每秒產量 × `clickShare`」之後，它在每個境界都值同樣的秒數：

| 境界 | 改之前 | 改之後 |
|---|---|---|
| 築基 | 0.18 秒 | 0.31 秒 |
| 金丹 | 0.006 秒 | 0.136 秒 |
| 化神 | 0.0000 秒 | 0.130 秒 |
| 飛昇 | 0.0000 秒 | 0.130 秒 |

換算成手感：狂點 5 下/秒 ≈ 自動產量的 65%，而且從金丹到飛昇都是 65%。想讓打坐更重要就調高 `clickShare`（或降低指玄功／天人交感的價格）。

### 遊戲的核心取捨

突破看的是「**手上當下持有多少靈氣**」，不是累計。所以靈氣有三個互相競爭的去處：蓋設施（賺更快）、買功法（賺更快，但突破就沒了）、存起來衝關。

而且**悟性的獲得量會隨你突破時囤的靈氣成長**（開根號遞減，囤 4 倍只換 2 倍）。所以「早點衝關」和「多囤一點」不只是快慢之爭，是**進度 vs 永久戰力**之爭。

`test.html` 會告訴你：全部法寶要 368 悟性，但每關剛好達標就衝只拿得到 176——想收齊法寶，就非囤不可。

## 怎麼裝到 iPhone 上玩

1. 確認 **iPhone 和 Mac 連同一個 Wi-Fi**
2. 用 iPhone 的 **Safari** 打開伺服器印出的那個 `192.168.x.x` 網址
3. 按底下的**分享**鈕 → 往下滑 → **加入主畫面**
4. 從主畫面的太極圖示啟動

從主畫面啟動時會是全螢幕、沒有網址列，看起來就跟一般 App 一樣。存檔存在手機裡，關掉再開會接上進度。

> 玩的時候 Mac 上的伺服器要開著。想要「不開電腦也能玩」，就是下面「之後可以做的事」第一項。

## 你要改的檔案：`js/content.js`

**這個檔案是你的地盤，其他檔案都不用碰。**

改完存檔，回瀏覽器重新整理就會生效（伺服器已設定成不讓瀏覽器快取，所以你一定看得到最新的）。

### 境界

```js
{ name: "金丹", requirement: 1e5, multiplier: 75, insight: 3, successRate: 1,
  note: "靈氣凝而成丹，壽元大增。" },
```

| 欄位 | 意思 |
|---|---|
| `requirement` | 突破**進入**這個境界要多少靈氣（第一個必須是 0） |
| `multiplier` | 到達後修煉速度變幾倍（**總倍率**，不是疊加） |
| `insight` | 突破到這裡的悟性基礎值（實際還會隨囤積量成長） |
| `successRate` | 渡劫成功率，1 = 一定成功。法寶可以往上加 |
| `note` | 突破時跳出來的那句話 |

### 修煉設施

`baseCost`（第 1 個的價格）、`costGrowth`（每買一個貴幾倍）、`baseRate`（每個每秒產多少）。

### 功法（靈氣買，突破後散去）

```js
{ id: "f_array1", name: "聚靈訣", icon: "📖", desc: "聚靈陣產量 ×2。",
  cost: 900, target: "array", multiplier: 2, requireOwned: 10 },
```

`target` 填修煉設施的 id，或 `"click"`（打坐）、`"all"`（全部設施）。
`requireOwned` 是「擁有幾個 target 才會上架」——一開始就攤出二十個功法只會讓人眼花。

### 法寶（悟性買，永久保留）

```js
{ id: "b_off1", name: "須彌芥子", icon: "🎒", desc: "離線收益上限 +8 小時。",
  cost: 8, effect: "offlineHours", value: 8 },
```

`effect` 只有四種，程式只認得這四個：

| effect | 意思 | 算法 |
|---|---|---|
| `click` | 打坐所得 ×value | 乘法 |
| `power` | 戰力 ×value | 乘法 |
| `allRate` | 所有設施產量 ×value | 乘法 |
| `clickShare` | 打坐額外獲得 value 比例的每秒產量 | 加法 |
| `offlineHours` | 離線上限 +value 小時 | 加法 |
| `tribulation` | 渡劫成功率 +value（0.1 = 10%） | 加法 |

> 加新的 effect 種類時，記得同步更新 `test.html` 裡的白名單——它是刻意手寫的，不從程式碼推導，這樣 effect 打錯字才抓得到。（我自己已經忘記兩次，兩次都被它抓包。）

加新的境界、設施、功法、法寶**都不會弄壞舊存檔**，新的自動從 0 開始。

### 旋鈕

| 想調什麼 | 改哪裡 |
|---|---|
| **打坐太廢／太強** | **`clickShare`（見上面那段）** |
| 機緣太常／太少出現 | `fortunes` 的 `minInterval` / `maxInterval` |
| 機緣太難點到 | `fortunes` 的 `lifetime`（停留幾秒） |
| 心魔太常抽到 | `fortunes.outcomes` 裡心魔的 `weight` |
| 每個境界要花多久 | `realms` 的 `multiplier`（調高 = 變快） |
| 渡劫太容易死 | `realms` 的 `successRate`，或調低法寶的 `tribulation` 成本 |
| 悟性太少／太多 | `realms` 的 `insight`、`layers` 的 `insight` |
| 打怪太卡關 | `layers` 的 `bossHp`，或 `combat.bossTimeLimit` |
| 前期節奏 | 各設施的 `baseRate` |
| 後期漲價太兇 | `costGrowth`（1.15 是經典值，1.07 會鬆很多） |
| 離線最多算幾小時 | `offlineCapHours`（注意：宗門弟子的道行**不吃**這個上限） |
| 弟子太快／太慢養滿 | `sect` 的 `hoursPerLevel`、`maxLevel` |
| 弟子加成太強／太弱 | 各弟子的 `base`、`sect.perLevel` |

**想從頭玩**：畫面最下面有「重置存檔」。

## 改壞了怎麼辦

打開 `http://localhost:8000/test.html`。

**400 多項驗算**，看到綠色的「全部通過」就沒事。它會抓出這些**不會報錯但會讓遊戲壞掉**的設定：

- 境界門檻沒遞增（會一次突破好幾層）
- 突破後倍率反而變低
- 功法的 `target` 指到一個不存在的設施（買了完全沒效果）
- 法寶的 `effect` 打錯字（程式不認得就默默沒作用）
- 乘法效果的 `value` 小於 1（買了反而變弱）

最下面還有兩行**參考數據**：每個境界大概是前一個的幾倍時間（目前約 2.0 倍），以及法寶總價 vs 一輪能拿多少悟性。調數值時看這兩行最快。

## 檔案各是做什麼的

```
index.html        畫面的骨架
serve.py          開發用伺服器（會叫瀏覽器不要快取，不然你改了看不到）
test.html         驗算頁
manifest.json     主畫面 App 的設定
css/style.css     長相
icons/            主畫面圖示（太極，由 Python 直接畫出來的）
js/
  content.js      ★ 你的檔案：境界、設施、功法、法寶、全部數值
  economy.js      成本／產量／加成／悟性／成功率的數學（純函式，所以驗算得到它）
  state.js        存檔、讀檔、離線收益、突破、買東西
  portrait.js     人物立繪（隨境界與裝備變，也是程式畫的）
  sound.js        音效（Web Audio 當場合成，不載音檔）
  ui.js           畫面更新
  main.js         主迴圈
```

## 之後可以做的事

- **不用開電腦也能玩**：把這個資料夾推到 GitHub Pages（免費、附 HTTPS）。有了 HTTPS 才能加 service worker，那時才會變成真正可離線的 App，走到哪都能玩。不需要 Apple 開發者帳號。
- **上 Android**：同一份程式碼用 Capacitor 包成 APK，不用重寫。
- **玩法**：成就、事件（奇遇、走火入魔）。如果覺得飛昇之後就沒事做了，可以加**輪迴轉世**——飛昇後回到凡人，但保留一部分悟性，那是放置遊戲的第二層 prestige。

## 已知的事

- **iOS 的原生 App 版本做不了**，因為你的 Mac 最高只能裝 Xcode 14.2（macOS 12 的上限），而它最高只能部署到 iOS 16 的裝置，你的 iPhone 是 iOS 26。這也是當初選網頁而不選 Godot 的原因——網頁這條路今天就能在你手機上跑。
- 數字上限約 `1.8e308`（JavaScript 浮點數的極限）。以現在的數值設計玩到那裡要非常久。
